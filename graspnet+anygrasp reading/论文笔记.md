# 论文阅读笔记

## AnyGrasp (IEEE T-RO, 2023)

> Fang et al., SJTU | 核心目标：又快又稳的 7-DoF 抓取姿态预测 + 动态跟踪

### 核心思路

```
场景点云 → 一次前向 → n 个最优抓取 + 特征向量（用于跟踪）
        不分割物体     障碍感知、COG 稳定分数内建评分
```

**密集预测**：对点云中每个可能的位置都预测抓取，不是 VAE 随机采样。每个种子点出 12 旋转 × 5 深度 = 60 种组合，取最高分的。

**COG 稳定分数**：最终分数 = 抓取分数 × (1 − 稳定分数)。稳定分数 = 质心到抓取面的归一化距离。质心偏离越远，分数打折越多。

**动态跟踪**：每帧输出 256 维特征向量 → 余弦相似度跨帧匹配 → 运动物体也能追着抓。

### 网络结构

```
点云 → Backbone → 热力图 → Graspable FPS → 1024 种子点
    → View 选择（300 选 1）→ Cylinder Grouping → MLP
    → 60 种组合（12 旋转×5 深度），每种预测：分数+宽度+稳定分数
    → 时序模块：Seed+Grasp+Color+Pose 特征 → MLP → 256 维 → 对比学习
```

- **种子点**：网络筛选出的"值得考虑抓取"的位置（1024个），只对这些做精细预测
- **Cylinder Grouping**：沿抓取方向在圆柱区域内采点提取局部几何特征（K=16）
- **View**：爪子从哪个方向靠近（300 个离散方向选 1）
- **面内旋转**：方向定了之后手指绕那个方向转多少度（12 个离散值）
- **接近深度**：爪子基座离物体表面多远闭合（0.5/1/2/3/4 cm）
- **宽度**：手指张开多大

### 训练

| 环节 | 内容 |
|------|------|
| 数据 | GraspNet-1Billion + 自采 104 物体 → 268 场景 |
| 标注 | 3D扫描 → 对踵分析(自动) → 物体6D位姿(人工) → 投影到场景 → 碰撞检测 |
| 稳定分数标签 | COG 到抓取面距离归一化到 [0,1]（假设均匀密度刚体） |
| 关联标签 | 相邻视角配对，物体坐标系下算 d(G₁,G₂) ≤ 0.1 → 同一对 |
| 阶段一 | 训几何模块(GSNet改进)，从头训，分类+回归 Loss |
| 阶段二 | 冻结几何模块，训时序模块，对比 Loss |
| 对比 Loss | 配对抓取的特征相似度必须 > 所有非配对（不是"拉近"，是"脱颖而出"） |

### 实验

| 指标 | 结果 |
|------|------|
| 静态清箱（300+ 物体） | **93.3%**（DexNet 4.0: 72%，人类: 93.9%） |
| 速度 | 900+ MPPH（UR5 单臂），决策 <200ms |
| 动态抓鱼 | 75.5%（启发式跟踪: 62.5%） |
| 深度噪声 | D435(±5mm) vs D415 几乎不降 |
| 仿真 vs 真实 | 真实数据训练 >> 仿真+噪声（Novel 物体差 ~30% AP） |

### 关键对比：vs 6D 位姿跟踪

- 位姿跟踪：管不了形变物体（软管）、遮挡时失败
- 抓取跟踪：只看抓取点附近几何，更鲁棒

## 6-DOF GraspNet (ICCV, 2019)

> Mousavian et al., NVIDIA | 核心目标：从一个物体生成多样化的 6-DoF 抓取

### 核心思路

```
单个物体点云 → VAE 采样 200 个抓取 → Evaluator 打分 → 梯度精炼 → 高质量抓取
 （需先分割）   （"想象"各种抓法）  （"评判"好赖）  （"微调"不准的）
```

**三阶段串行**：生成 → 评估 → 优化。和 AnyGrasp 的"一次前向全搞定"完全不同。

### 网络结构

**VAE 抓取采样器**：
```
训练时：Encoder(点云+真实抓取) → z(2维) → Decoder(点云+z) → 重建抓取
推理时：扔掉 Encoder，随机 z~N(0,1) → Decoder → 200 个抓取
```

- 隐空间 **2 维**最优（消融实验：1维容量不够，3-4维过拟合）
- KL 正则强制 z~N(0,1)，保证采样质量
- 输出：四元数(4维, L2归一化) + 平移(3维) = 7 个数字 = **6-DoF**（不预测宽度！）
- 重建 Loss 不用 R、T 直接比，而是**在爪子模型上预选点**，比较变换后世界坐标。好处：旋转和平移误差统一在"点的偏移"这一个尺度里，无需手动调权重

**Evaluator**：
```
物体点云 X + 爪子点云 Xg → PointNet → 成功概率 [0,1]
```
- 把爪子**渲染成点云**和物体点云拼一起——PointNet 天然处理空间关系，比输入抽象 [R,T] 数字强得多
- 训练：30% 正 + 30% 随机负 + 40% 难负（正样本平移±3cm/旋转±0.6rad）

**梯度精炼**：
```
g_new = g + η × ∂S/∂g
沿 Evaluator 梯度方向微调，重复 10 次。η 限制每次平移 ≤1cm
```

### 训练数据

| 环节 | 内容 |
|------|------|
| 物体 | ShapeNet 206 个（盒、圆柱、碗、瓶、杯） |
| 仿真 | FleX 物理引擎：随机采样候选 → 抓 → 摇 → 不掉=成功 |
| 规模 | 700 万次仿真 → 210 万成功抓取 |
| 类型 | **纯仿真**，零真实数据 |

### 评估指标

- **成功率**：预测的抓取中成功的比例（类似 precision）
- **覆盖率**：正样本空间 G* 中被预测抓取覆盖的比例（类似 recall）
- 两者画成功率-覆盖率曲线（=抓取领域的 PR 曲线），AUC 评估

### 实验

| 指标 | 结果 |
|------|------|
| 真实机器人（17 物体） | **88%**（GPD: 47%） |
| GPD 在杯子上 | 6%（法向量在薄边不准 → 没抓取）|
| 消融 | 2 维隐空间最优；精炼 10 次 plateau；VAE > 几何采样 |
| 速度 | VAE+Evaluator 0.04s + 精炼 0.3s×N，远慢于 AnyGrasp |

## 两篇对比速览

| | 6-DOF GraspNet (2019) | AnyGrasp (2023) |
|---|---|---|
| **输入** | 单个物体点云（需先分割） | 全场景点云（不分割） |
| **核心方法** | VAE 采样 + Evaluator + 梯度精炼 | 密集预测 + COG 稳定分数 + 对比学习 |
| **多样性来源** | 隐空间随机采样 z | 种子点覆盖全场 |
| **评分** | Evaluator 单独打分 + 梯度优化 | 抓取分数×(1-稳定分数) 一次完成 |
| **输出** | 一个物体的 N 种抓法 | 全场景 n 个物体各一个最优抓取 |
| **宽度** | 固定，不预测 | 预测（7维抓取） |
| **训练数据** | 仿真（206 物体） | 真实（144 物体） |
| **成功率** | 88%（17 物体） | 93.3%（300+ 物体） |
| **速度** | 慢（精炼 10 次） | 快（一次前向 <200ms） |
| **动态跟踪** | ❌ | ✅（75.5% 抓鱼） |
| **关系** | NVIDIA，独立路线 | 继承 GraspNet-1Billion + GSNet 路线 |

**关键区别**：6-DOF GraspNet 问"这个物体我能怎么抓？给我所有方案。" AnyGrasp 问"这堆东西我抓哪个最好？给我一份计划。"

## 关键概念速查

- **6-DoF**：3 个位置(x,y,z) + 3 个朝向(roll,pitch,yaw)
- **7-DoF 抓取**：6-DoF + 爪子宽度
- **点云**：深度相机输出的 3D 点集合，不是 RGB 图
- **对踵点**：物体表面法向量相反的两点，两手指刚好能夹住
- **NMS**：同一物体上多个高分抓取只保留分数最高的
- **种子点**：网络筛选的"可能可抓"位置，只对这些做完整预测
- **接近深度**：爪子离物体多远闭合（不是机械臂移动距离）
- **宽度**：手指张多开
- **四元数**：4 维表示旋转，无万向锁死。ROS 默认
- **对比学习**：让配对特征"脱颖而出"而不是"拉近到零"
- **Parallel Gripper**：平行夹爪，两指平行开合（和并行计算无关）
- **Sim-to-Real**：仿真训练→真实部署。6-DOF GraspNet 证明了可行，但 AnyGrasp 证明了真实数据更好
